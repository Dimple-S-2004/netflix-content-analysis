# Netflix Content Strategy Analysis

## Project Overview
Performed Exploratory Data Analysis (EDA) on Netflix content data to uncover trends in genres, ratings, countries, and content growth.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- WordCloud

## Key Insights
- Movies dominate Netflix's catalog.
- USA contributes the highest amount of content.
- Drama and International Movies are among the most common genres.

## Dataset
Netflix Titles Dataset
